## About me

I'm **Alvin** — on GitHub as **Suisei** ([@Alvinagustus](https://github.com/Alvinagustus)).

I build in the open on **NEAR**: AI agents that duel, transact, and defend money on-chain. My recent work is in **Rust** for NEAR smart contracts, with **Python** for agent tooling, identity kits, and RL swarms.

- 🔭 Currently building: **[Aegis](https://github.com/Alvinagustus/aegis)** and **[Overclock](https://github.com/Alvinagustus/Overclock)** — both from the NEAR hackathon
- 🤖 Focus: on-chain AI agents, commit–reveal game logic, and Chain Signatures
- 🛡️ Interested in: policy layers for money, anti-drain protection, and agent identity
- ☄️ Theme of this profile: a blue comet on a night sky — calm on the surface, all-in when it matters
